# anchor.md

A CLAUDE.md configuration file generator. Select your tech stack, set your engineering vibe, and get a production-grade CLAUDE.md with agentic directives for Claude Code.

## Features

- **Categorized Stack Selection** — 21 technologies across Frontend, Mobile, Backend, Database, and Tooling
- **Engineering Vibe** — Speedrun, Balanced, Strict TDD, or Architect mode tailors the governance level
- **Agentic Directives** — Generated rules tell Claude Code exactly how to behave (terminal discipline, type safety, testing, destructive action guards)
- **Live Preview** — IDE-styled dark preview pane updates in real-time
- **Copy / Download** — One-click copy or download as `CLAUDE.md`

## Stack

- React 19 + TypeScript (strict)
- Vite + Tailwind CSS v4
- Zustand (state persistence)
- Zod (schema validation)
- react-markdown + rehype-highlight (preview)

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
